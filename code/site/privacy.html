Privacy Policy

Last updated: February 2025. How sk-mockAPI and this site handle your data.

Overview

sk-mockAPI is a Chrome extension that lets you intercept API requests in the browser and return mock responses. This policy explains what data the extension and this website collect, and how it is used.

The sk-mockAPI extension

The extension runs entirely in your browser. It does not send your data to any external server.

  • Mock rules and responses — Stored locally in your browser (e.g. Chrome’s extension storage). They are not transmitted to us or any third party.
  • Request interception — The extension intercepts only the requests you configure (by URL pattern). Request and response data stay on your device.
  • No analytics or tracking — The extension does not include analytics, tracking scripts, or any code that sends usage data elsewhere.

This website

This site is static. We do not run our own servers to collect personal data from visitors.

  • Hosting / CDN — If you access the site through a host (e.g. GitHub Pages, Netlify, Vercel), that provider may log IP addresses and request metadata according to its own privacy policy. We do not control or receive that data.
  • Fonts — We use Google Fonts (fonts.googleapis.com). Your browser may send requests to Google; see Google’s Privacy Policy for how they handle that data.
  • No cookies or forms — We do not set cookies or collect information through forms on this site.

Chrome Web Store

If you install sk-mockAPI from the Chrome Web Store, Google’s terms and privacy policies apply to that installation. We do not receive any personal data from the Store about who installs the extension.

Changes

We may update this privacy policy from time to time. The “Last updated” date at the top will be revised when we do. Continued use of the extension or site after changes means you accept the updated policy.

Contact

For questions about this privacy policy or sk-mockAPI, you can open an issue in the project repository or contact the developer (sachinkondana) through the channels listed there.
